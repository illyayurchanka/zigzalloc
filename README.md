# zigzalloc

`malloc` from the [Memory Allocators 101](https://arjunsreedharan.org/post/148675821737/memory-allocators-101-write-a-simple-memory) tutorial ([C source](https://github.com/arjun024/memalloc)), written in Zig 0.17 and optimized by looking at [mimalloc](https://github.com/microsoft/mimalloc).

Written by hand. AI was used as an assistant for reading mimalloc and debugging.
